If you have limited time, use this order:

**1. HTML fundamentals** ⭐⭐⭐
↓
**2. Forms** ⭐⭐⭐
↓
**3. Semantic HTML** ⭐⭐⭐
↓
**4. Accessibility** ⭐⭐⭐
↓
**5. Tables** ⭐⭐
↓
**6. Images & responsive images** ⭐⭐
↓
**7. `async` / `defer`** ⭐⭐⭐
↓
**8. SEO** ⭐⭐
↓
**9. Multimedia** ⭐
↓
**10. Modern HTML APIs/features** ⭐

### 🧠 After HTML, move to:

**HTML → CSS → JavaScript → DOM → Git → HTTP/REST APIs → React → Projects → Interview preparation**

Don't spend weeks memorizing tags. **Learn the concept, write the HTML yourself, and build small pages.**
